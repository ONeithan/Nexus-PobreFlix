## 🇧🇷 Português (Brasil)

### 🚀 O que é o Nexus PobreFlix?
Este é o plugin oficial da experiência **Nexus PobreFlix**. Um fork de alto desempenho do projeto JMSFusion, reconstruído para oferecer uma interface premium, estilo "Netflix", com tema roxo característico e tradução cirúrgica para o Português do Brasil.

### ✨ Diferenciais da Edição Nexus (v1.0.0.0)
| Funcionalidade | Descrição |
|---|---|
| 🟣 **Identidade Nexus** | Tema roxo exclusivo (`#7a5cff`) em toda a interface de configuração e componentes visuais. |
| 🇧🇷 **Localização 100%** | Tradução completa de todos os menus, botões e mensagens, incluindo strings anteriormente hardcoded em Turco. |
| ⚡ **Splash Screen** | Tela de carregamento personalizada ao iniciar o Jellyfin, garantindo a marca PobreFlix. |
| 📦 **Autonomia Total** | Novo GUID independente, permitindo instalação paralela ou substituição limpa de versões anteriores. |
| 🎬 **Layout Premium** | Slider de destaques, Studio Hubs e interface de trailers otimizada para TVs e Desktop. |

### 🛠️ Instalação via Repositório (Recomendado)
Para receber atualizações automáticas, adicione este link em **Painel → Plugins → Repositórios**:

```
https://raw.githubusercontent.com/ONeithan/Nexus-PobreFlix/main/manifest.json
```

### 🛠️ Instalação Manual
1. Baixe o ZIP da [Release v1.0.0.0](../../releases).
2. Extraia o conteúdo na pasta `plugins/NexusPobreFlix` do seu servidor Jellyfin.
3. Reinicie o servidor.
